# Image-Segmentation-GUI-Toolkit
Image Segmentation GUI Toolkit adalah aplikasi desktop berbasis Python, Tkinter, dan OpenCV yang dirancang untuk memvisualisasikan dan mengeksplorasi berbagai metode segmentasi citra secara interaktif. Proyek ini dikembangkan sebagai alat edukasi, eksperimen, dan demonstrasi konsep dasar pengolahan citra digital.
